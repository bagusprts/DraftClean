# DraftClean

Optimizes high-performance data processing with automated backup and real-time data synchronization across the database system.

DraftClean is built to be simple and practical, focusing on doing one thing well.

**Why DraftClean?**

- Optimizes high-performance data processing with
- automated backup and real-time data
- synchronization across the database system

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/DraftClean.git`
2. `cd DraftClean`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
